A file added to a new project can keep uploading after you leave that screen. The saved table appears when it matches the file. A table card shows the same weight, decimals, and labels as its dialog, and an ordinal scale can sit where a number is asked for.

- Upload continues in the background
- A retry stays on the same project
- Saved stays in step with the table
- The card and the dialog agree
- Ordinal scales in numeric slots
