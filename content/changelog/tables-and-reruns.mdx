A banner net stays on that table. Saving a net onto the variable is a separate step. Re-running a table from an Excel file keeps the R check, and a comparison in the summary has to match the cells.

- Re-run of an xlsx table stays verified
- A false "highest" sentence is dropped
- Inline tables in an answer render as tables
