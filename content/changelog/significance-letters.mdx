Column letters now run on the weighted banner, not a separate test menu. When a client asks where a letter came from, the cell still points at the respondent rows.

- 95% and 90% column proportions
- Low-base cells stay visible and skip the letter
- Letters export into Excel and PowerPoint with the grid
