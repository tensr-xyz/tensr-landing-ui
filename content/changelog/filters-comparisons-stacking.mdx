A filter used for one analysis stays on that run. Naming two groups keeps a two-group comparison. Means report the valid base. NPS asks what to do when the scale is not 0 to 10. Drivers leave out identifiers, free text, and multi-response text. A weighted table does not change the dataset. Stack and append find Merge Datasets, and stacking says when those rows are already in the file. The data quality report is in plain language. An approval plan is shown once, and saving opens that version.

- Filters on a single run
- Two-group comparisons
- Valid bases on means
- NPS scale check
- Drivers predictors
- Weighted tables without changing the dataset
- Stacking, including stack and append in the command palette
- Plain-language data quality
- One approval plan, then the saved sheet
