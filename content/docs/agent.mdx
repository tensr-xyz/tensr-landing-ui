Chat is a tab in the project, beside Details, Sources, Responses, Tables, and Report. Add the file on Sources first. The box then reads **Ask about** that file. Type `@` to point at a column.

The mode switch under the box is **Ask**, **Plan**, or **Agent**. Agent is the default. The choice is stored for the project.

| Mode | What it does |
| --- | --- |
| **Ask** | Read-only answers. Nothing is edited and no analysis is run. |
| **Plan** | Writes a plan and waits. **Approve** runs it. **Edit plan** drops it so you can ask again. |
| **Agent** | Runs the step when it is confident, and asks when it is not. |

## What you can attach

CSV, Excel, or SPSS, up to 8 MB per file. A larger file is rejected with “is larger than 8 MB”. The project file itself is added on [Sources](/docs/import), not as a chat attachment.

## What it can do

- Run the same analyses as the menu, from a sentence in Chat
- Hand a table to **Tables**, and a saved table to **Report**
- Apply a filter or a weight, and say when the rows are already in the file
- Chain a merge when you attach several files and ask to merge and weight them. See [Merging](/docs/merging)

## What it cannot do

Another project, and the public web, are marked coming soon under the box. Chat reads the file on Sources and what you attach in the thread.
