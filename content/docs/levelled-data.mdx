---
title: Levelled data
description: A loop such as brands per respondent stays grouped, and Custom Tables can tabulate at that level.
---

A grid that repeats the same questions for each brand, or each trip, does not have to be flattened before you table it.

## Confirm the loop

Variable view lists loop proposals. A complete match reads like “aware, owns, likes asked for brands A, B, C”. **Confirm** groups those columns. A partial match stays a proposal until the columns line up.

You can rename the loop. The label starts as Brand.

The same proposals appear in Custom Tables, with the same confirm step.

## Choose the level

Once a loop is confirmed, Custom Tables has a **Level** control.

- **Respondent** tables the file as one row per person.
- The loop’s own name, such as Brand, tables at that level. The picker then offers the loop item, the questions in the loop, and the respondent columns.

You do not reshape the file by hand to switch between those levels.
