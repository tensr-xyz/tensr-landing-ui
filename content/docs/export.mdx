There are two export paths: the dataset, and the banner you signed off.

## Dataset — Export Data

Data → Import & Export → Export Data. Default format is CSV.

| Format | File |
| --- | --- |
| CSV (.csv) | Same column names as SPSS, including `weight` when present |
| JSON (.json) | Dataset JSON |
| SPSS (.sav) | Variable labels, value labels, measurement level, missing ranges — plus a companion `.sps` |
| Stata (.dta) | Variable labels and value labels |

SPSS cannot take the weight-variable flag from the `.sav` pyreadstat writes, so the file opens unweighted. The companion syntax is:

```
* Open <file>.sav and run this syntax.
* <weight label>
* pyreadstat does not write the SPSS weight-variable flag, so the file opens unweighted.
WEIGHT BY weight.
EXECUTE.
```

If there is no weight column, the `.sps` is `* This dataset has no survey weight column.`

## Banner — Excel and PowerPoint

From the banner grid: Excel (`banner.xlsx`) and PowerPoint (`banner.pptx`).

Excel is the audit record. The provenance sheet carries bitsets, weight identity, and the convention tuple so the file stands alone.

PowerPoint is not an audit record. Convention is in the slide notes only.

Weight identity is on both. Unweighted tables store `explicit_null`.

## Analysis reports

Reports can download tables as CSV (with run id, dataset id, fingerprint) and the full write-up as Markdown. HTML is produced for print. SPSS syntax sits in a collapsible **SPSS syntax (reference)**. The R script is under **Reproducibility (R)** — see [The R script](/docs/r-script).
