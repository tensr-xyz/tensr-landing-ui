---
title: Using plugins
description: Install a plugin from the marketplace. The agent and the command palette can call it.
---

Open **Plugins**. The page is the marketplace: methods and checks your team can add. Search, or filter to the ones you have installed.

**Install** adds the plugin to your workspace. A paid plugin has to be purchased first. Prices are in pounds, and checkout goes through the creator’s Stripe account.

An installed plugin shows up in ⌘K, and the agent can call it. A run that uses one stays with the rest of the project’s results.

Plugins run inside Tensr, with no network access. One workspace’s installs do not reach another’s.
