## When to use it

Use probit regression for the same binary outcome as logistic regression when you want the slope on the probit scale. A positive slope still means the predictor makes a “yes” more likely. There is no odds ratio on this table.

## Assumptions

The outcome is binary. The underlying probit model is a fair summary, and the rows are independent. Perfect separation makes the slopes unstable, the same way it does for logistic regression.

## Running it in Tensr

<Steps>
<Step>Analyze → Regression → Probit. In chat: “Probit regression of passed on practice.”</Step>
<Step>Dependent is the 0/1 outcome, unless derive_binary_from builds it. Independents need at least one predictor.</Step>
<Step>Confidence level starts at 0.95. Include constant is on the request and is not forwarded, so the fit keeps an intercept.</Step>
</Steps>

## Reading the output

Same 24 students and the same `passed` and `practice` columns as the logistic example.

| Term | Estimate | p-value |
| --- | ---: | ---: |
| const | -3.769 | .007 |
| practice | 0.94 | .006 |

Metrics: pseudo R² 0.541, model χ² 17.983, model p < .001, AIC 19.288, N 24. Model p < .001 means practice, as a model, is not a plausible zero. The practice row p = .006 is the slope test.

Marginal effects at the mean:

| Predictor | Marginal effect (dP/dX at mean) |
| --- | ---: |
| practice | 0.375 |

That 0.375 is the change in predicted probability of passing for a one-unit practice increase, evaluated at the mean of practice. It is not an odds ratio.

## Reporting (APA 7)

A probit model predicted passing from practice (N = 24). The model was significant, χ² = 17.98, p < .001. The practice slope was positive, estimate = 0.94, p = .006. The marginal effect at the mean was 0.38.

## Coming from SPSS

Analyze → Regression → Probit.

SPSS Probit is often aimed at dose-response tables. Tensr fits a binary probit from row-level 0/1 data and a numeric predictor.
