## When to use it

Use MaxDiff when each person saw a set of items and picked the best and the worst. The score is how often an item wins, or a logit of those choices, rescaled from 0 to 100. A full choice-based conjoint, with attributes and levels, is [conjoint](/docs/analyses/conjoint).

## Running it in Tensr

<Steps>
<Step>Analyze → Survey techniques → MaxDiff (counting / MNL). In chat: “Run MaxDiff on best and worst.”</Step>
<Step>Design exports a long file and a wide file for the survey tool. Tensr does not host the survey.</Step>
<Step>Analyse marks the best and worst columns. Set columns are the alternatives shown together. Counting is the default. MNL is the logit. Individual utilities fit one score per person.</Step>
</Steps>

## Reading the output

Counting reports how often each item was chosen best against how often it was shown. MNL reports a utility. Both can be rescaled from 0 to 100 so the top item reads as 100. Individual utilities give one score per item for each person.

## Coming from SPSS

SPSS has no MaxDiff item. Tensr’s item is Analyze → Survey techniques → MaxDiff (counting / MNL), with a design export and an analyse step on the returned file.
