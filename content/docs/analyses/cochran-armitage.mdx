## When to use it

Use Cochran–Armitage when the outcome is binary and the groups have an order. It is the z-test cousin of the Mantel–Haenszel trend test.

## Assumptions

The group column must sort into the intended order. The outcome has two levels.

## Running it in Tensr

<Steps>
<Step>Analyze → Correlate → Cochran-Armitage Trend. In chat: “Cochran–Armitage trend of dose by illness.”</Step>
<Step>Group column is ordered. Outcome column is binary.</Step>
</Steps>

## Reading the output

The same dose groups against a response that rises from low to high.

Cochran–Armitage trend test: `response` by `dose` (decreasing trend). The primary result is significant (p = < .001). This is large enough, in this sample, to treat the comparison this page is about as a real association rather than noise. Metrics: Z = -29.811; p (two-tailed) = < .001; p (one-tailed) = > .999; Trend = decreasing.
