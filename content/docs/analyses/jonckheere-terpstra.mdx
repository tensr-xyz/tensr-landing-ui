## When to use it

Use Jonckheere–Terpstra instead of Kruskal–Wallis when the groups have an order and you expect the scores to rise or fall along that order.

## Assumptions

Groups are independent. Pass `group_order` when the label sort is not the order you mean. Otherwise numeric labels sort numerically and other labels sort alphabetically.

## Running it in Tensr

<Steps>
<Step>Analyze → Nonparametric Tests → Jonckheere–Terpstra. In chat: “Jonckheere–Terpstra test of score by method.”</Step>
<Step>Set group order to lecture, online, workshop when those names should be the sequence.</Step>
</Steps>
