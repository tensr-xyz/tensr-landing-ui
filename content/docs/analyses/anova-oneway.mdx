## When to use it

Use one-way ANOVA when a numeric outcome might differ across three or more separate groups. For example: do exam scores differ between lecture, online, and workshop teaching? The test asks whether the group means are all the same. It does not, by itself, say which pair differs. That is what a post-hoc test is for.

Two groups only: use the [independent-samples t-test](/docs/analyses/ttest-independent).

## Assumptions

Scores are numeric, and each person is in one group. Within each group, scores should be roughly normal, and the groups should have similar spread.

Tensr stores Levene’s test on the result. The default is the median-centre version. You can switch it to Brown–Forsythe or turn it off. Levene’s p below .05 means the spreads differ. This procedure does not print a Shapiro–Wilk table. If the spreads differ, use Welch (`use_welch`, off by default) or the [Kruskal–Wallis test](/docs/analyses/kruskal-wallis).

## Running it in Tensr

<Steps>
<Step>Analyze → Compare Means → One-Way ANOVA. In chat: “One-way ANOVA of score by method.” Tukey is not a separate menu item. Ask for Tukey and Tensr runs this ANOVA with post hoc set to tukey.</Step>
<Step>Group column is the grouping variable. Value column is the numeric outcome. Groups with fewer than two rows are dropped, and the report marks them excluded.</Step>
<Step>Post hoc starts at none. Effect size starts at eta squared. Homogeneity starts at Levene. Group descriptives start on. The chart starts as a box plot. Missing values start as listwise.</Step>
</Steps>

## Reading the output

Twenty-four students, eight in each teaching method. This run used the defaults plus Tukey.

Group means. Status is included unless the group was too small to analyse.

| Group | n | Mean | Status |
| --- | ---: | ---: | --- |
| Lecture | 8 | 66.875 | included |
| Online | 8 | 73.5 | included |
| Workshop | 8 | 79.5 | included |

ANOVA. η² is the proportion of score variance that sits between teaching methods. 0.908 means about 91% of the variation in this toy set is between methods, which is only believable because the groups barely overlap.

| Source | SS | df | MS | F | p | η² |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Between Groups | 638.083 | 2 | 319.042 | 103.274 | < .001 | 0.908 |
| Within Groups | 64.875 | 21 | 3.089 | — | — | — |
| Total | 702.958 | 23 | | | | |

F compares between-group variance with within-group variance. df are 2 and 21 (groups minus 1, and N minus the number of groups). p < .001 means the three means are not all equal.

Tukey comparisons. The mean difference is Group B minus Group A. Every pair differs.

| Group A | Group B | Mean difference | p (adj) | CI low | CI high | Reject H₀ |
| --- | --- | ---: | --- | ---: | ---: | --- |
| Lecture | Online | 6.625 | < .001 | 4.41 | 8.84 | True |
| Lecture | Workshop | 12.625 | < .001 | 10.41 | 14.84 | True |
| Online | Workshop | 6 | < .001 | 3.785 | 8.215 | True |

Levene’s test on this run was F = 0.42, p = .662, so the spreads are similar. The chart is a box plot titled “score across method.”

## Reporting (APA 7)

A one-way ANOVA tested exam scores across lecture, online, and workshop teaching (n = 8 per method). Teaching method had a significant effect, F(2, 21) = 103.27, p < .001, η² = .91. Levene’s test was not significant, F = 0.42, p = .662. Tukey tests showed that every pair of methods differed, all p < .001. Workshop scores were highest (M = 79.50), then online (M = 73.50), then lecture (M = 66.88).

The ANOVA table prints η² as 0.908. APA drops the leading zero for a statistic that cannot exceed 1.

## Coming from SPSS

Analyze → Compare Means → One-Way ANOVA.

SPSS puts Welch and the post-hoc tests in the same dialog. Tensr’s Welch switch is `use_welch`, and post hoc is `post_hoc`. SPSS Options also offers a means plot. Tensr’s chart control is `output_chart` (`boxplot`, `means_plot`, or `none`).
