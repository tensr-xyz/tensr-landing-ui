title: Sign test
description: Test whether paired scores change direction, ignoring how large the change is.
category: Non-parametric
---

## When to use it

Use the sign test when you only care whether each pair went up or down. It is the simpler alternative to the [Wilcoxon signed-rank test](/docs/analyses/wilcoxon-signed-rank) and the [paired t-test](/docs/analyses/ttest-paired).

## Assumptions

Each row is one pair. Ties (no change) are counted and then set aside.

## Running it in Tensr

<Steps>
<Step>Analyze → Nonparametric Tests → Related Samples. In chat: “Sign test of before and after.”</Step>
<Step>Before column and after column are the two measurements.</Step>
</Steps>

## Reading the output

A second set of 48 pairs whose true change is about zero. The sign test only counts who went up and who went down.

Sign test comparing `before_ns` and `after_ns`, n = 48 pairs. The primary result is not significant (p = .471). This is not large enough to treat the comparison this page is about as a reliable association. The result is non-significant: the data are still compatible with no effect. Metrics: Positive diffs = 27; Negative diffs = 21; p-value = .471.
