## When to use it

Use three-way ANOVA when three categorical factors might affect one numeric outcome. For example: do practice scores depend on sleep, caffeine, and practice schedule, including the ways those factors combine?

Read the three-way interaction first. If it is significant, the two-way patterns are not the same at every level of the third factor, and the main effects are a blunt summary.

## Assumptions

Each factor needs at least two levels, and Tensr asks for at least eight complete rows. A balanced design (the same number of scores in every combination) uses Type II sums of squares. An unbalanced or incomplete design uses Type III.

Tensr does not run Levene’s test or Shapiro–Wilk here. η² in the table is each term’s sum of squares divided by the total sum of squares, not partial η². There is no switch for that.

If a sum of squares comes out negative, the report warns that the model may be overspecified. Tensr then drops the three-way term and refits the two-way interactions. If squares are still negative, the run stops.

## Running it in Tensr

<Steps>
<Step>Analyze → Compare Means → Three-Way ANOVA. In chat: “Three-way ANOVA of score by sleep, caffeine, and practice.”</Step>
<Step>Factor A, factor B, and factor C are the three grouping columns. Value column is the numeric outcome.</Step>
<Step>Include interactions starts on. Confidence level starts at 0.95. There is no post-hoc control on this procedure.</Step>
</Steps>

## Reporting (APA 7)

Three-way ANOVA for `score`, n = 96. Report the estimate in the table. This procedure is not summarised by one p-value.

## Coming from SPSS

Analyze → General Linear Model → Univariate, with three fixed factors. Tensr’s stored path is Analyze → General Linear Model → Three-Way ANOVA. SPSS can print partial η² and post-hoc tests from that dialog. Tensr prints η² as SS / SS total and has no post-hoc option here.
