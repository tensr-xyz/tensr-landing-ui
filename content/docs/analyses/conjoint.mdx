## When to use it

Use conjoint when each person chose one profile from a set, and each profile is a combination of attributes and levels. The result is a part-worth for each level, and a share for a profile you specify. Best-worst on a list of items, without attributes, is [MaxDiff](/docs/analyses/maxdiff).

## Running it in Tensr

<Steps>
<Step>Analyze → Choice modelling → Conjoint. In chat: “Run conjoint on the choice column.”</Step>
<Step>Design names each attribute and its levels, then exports a long file and a wide file. Tensr does not host the survey.</Step>
<Step>Analyse marks the chosen profile. MNL is the default. Individual utilities fit one set of part-worths per person.</Step>
</Steps>

## Reading the output

MNL reports a part-worth for each level. A higher part-worth is the level people picked more often, holding the other attributes as they were shown. Individual utilities are the same part-worths, one respondent at a time. The choice simulator turns a set of profiles into shares.

## Coming from SPSS

SPSS has no conjoint item in the base menus. Tensr’s item is Analyze → Choice modelling → Conjoint. The simulator is a separate item, Choice Simulator, under Techniques.
