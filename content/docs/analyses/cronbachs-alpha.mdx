title: Cronbach’s alpha
description: Internal consistency of a set of items that should measure one thing.

## When to use it

Use Cronbach’s alpha when several items are supposed to measure the same construct, such as four questions on the same attitude. Alpha near 1 means the items rise and fall together. Alpha near 0 means they do not.

## Assumptions

Items are numeric and scored in the same direction. A reverse-worded item that was not reversed pulls alpha down and can make an item–total correlation negative. Rows with any missing item are dropped. Alpha is undefined if the total score does not vary.

## Running it in Tensr

<Steps>
<Step>Analyze → Scale → Reliability Analysis. In chat: “Cronbach’s alpha for q1 to q4.”</Step>
<Step>Select at least two item columns.</Step>
</Steps>

The menu key is `reliability_cronbach`. The alias `reliability` computes the same alpha and also flags an item whose correlation with the total is negative.

## Coming from SPSS

Analyze → Scale → Reliability Analysis, model Alpha. SPSS also prints the item statistics. Tensr stores alpha, the item–total correlation, and alpha if that item is deleted. There is no split-half or Guttman model on this request.
