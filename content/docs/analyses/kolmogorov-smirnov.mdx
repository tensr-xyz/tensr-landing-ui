## When to use it

The two-sample test asks whether two numeric columns could come from the same distribution. The normality option is an assumption check. On that option Tensr runs Shapiro–Wilk and labels the result `normality_shapiro`. For the Lilliefors correction, use [Lilliefors K-S](/docs/analyses/lilliefors-ks). For Shapiro–Wilk by name, use [Shapiro–Wilk](/docs/analyses/shapiro-wilk).

## Assumptions

Two-sample mode needs two numeric columns. Normality mode needs one numeric column with at least three values and at most 5000.

## Running it in Tensr

<Steps>
<Step>Analyze → Nonparametric Tests → K-S. In chat: “Kolmogorov–Smirnov test of lecture versus workshop.”</Step>
<Step>Test type starts at two_sample. Set it to normality to check one column.</Step>
</Steps>

## Reading the output

Eight lecture scores and eight workshop scores, entered as two columns.

| D | p | n |
| ---: | --- | ---: |
| 0.750 | .019 | 8 and 8 |

D = 0.75 means the largest gap between the two empirical distributions is three quarters of the sample. p = .019, so the two score columns do not look like the same distribution.

The normality option on the twelve-score column used for Shapiro–Wilk returned W = 0.941, p = .512, the same figures as that test.

## Reporting (APA 7)

A two-sample Kolmogorov–Smirnov test showed that the lecture and workshop scores differed, D = .75, p = .019.

## Coming from SPSS

Analyze → Nonparametric Tests → 1-Sample K-S, or 2 Independent Samples with the K-S box. SPSS’s one-sample K-S against a normal distribution uses the Lilliefors correction when the mean and SD are estimated from the data. Tensr’s normality option does not. Use Lilliefors K-S for that check.
