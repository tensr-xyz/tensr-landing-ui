## When to use it

Use negative binomial regression for counts when the variance is larger than a Poisson model allows. The table still reports an incidence rate ratio. The extra piece is the dispersion parameter α.

## Assumptions

The outcome is a non-negative count. Rows are independent. This fit uses a default dispersion when the model does not estimate one. Read the α line before you treat the model as a checked over-dispersion fit.

## Running it in Tensr

<Steps>
<Step>Analyze → Regression → Negative Binomial. In chat: “Negative binomial regression of absences on anxiety.”</Step>
<Step>Dependent is the count. Independents need at least one predictor.</Step>
<Step>Confidence level starts at 0.95. Include constant starts on.</Step>
</Steps>

## Reading the output

Twenty-four students. `absences` is a count. `anxiety` is the predictor. The fit warned that α was not set and used the default 1.0.

| Term | Estimate | 95% CI | IRR | p-value |
| --- | ---: | --- | ---: | ---: |
| const | 2.736 | [1.419, 4.053] | 15.425 | < .001 |
| anxiety | -0.271 | [-0.497, -0.044] | 0.763 | .019 |

The anxiety IRR is 0.763, so the expected count is smaller at higher anxiety. p = .019.
