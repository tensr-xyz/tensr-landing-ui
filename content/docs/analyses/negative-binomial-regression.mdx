## When to use it

Use negative binomial regression for counts when the variance is larger than a Poisson model allows. The table still reports an incidence rate ratio. The extra piece is the dispersion parameter α.

## Assumptions

The outcome is a non-negative count. Rows are independent. Tensr estimates α from the counts and refits the coefficients at that value. The report prints α, its standard error, and a likelihood-ratio comparison with a Poisson model. When the counts are not over-dispersed, α can collapse and the standard error stays blank.

## Running it in Tensr

<Steps>
<Step>Analyze → Regression → Negative Binomial. In chat: “Negative binomial regression of absences on anxiety.”</Step>
<Step>Dependent is the count. Independents need at least one predictor.</Step>
<Step>Confidence level starts at 0.95. Include constant starts on.</Step>
</Steps>

## Reading the output

A class of 24 absence counts is not over-dispersed, so α collapses and the Poisson comparison is not informative. This example uses an over-dispersed set of 180 visits, with anxiety as the predictor.

| Term | Estimate | SE | 95% CI | IRR | p-value |
| --- | ---: | ---: | --- | ---: | ---: |
| const | 1.082 | 0.113 | [0.860, 1.303] | 2.949 | < .001 |
| anxiety | 0.593 | 0.13 | [0.337, 0.849] | 1.809 | < .001 |

The anxiety IRR is 1.809, so the expected visit count is larger at higher anxiety. p < .001.

Metrics on this run:

| Metric | Value |
| --- | ---: |
| Dispersion α | 1.865 |
| α SE | 0.274 |
| LR vs Poisson χ² | 491.58 |
| LR vs Poisson p | < .001 |
| AIC | 766.091 |
| Deviance | 184.366 |
| Observations | 180 |

α is estimated, and its standard error is filled in. The likelihood-ratio test says this negative binomial fits better than a Poisson model of the same counts.

## Reporting (APA 7)

A negative binomial regression related visit counts to anxiety (N = 180). Anxiety was associated with more visits, B = 0.59, 95% CI [0.34, 0.85], IRR = 1.81, p < .001. Dispersion was α = 1.87 (SE = 0.27). The negative binomial fit better than a Poisson model, χ² = 491.58, p < .001.

## Coming from SPSS

Analyze → Regression → Negative Binomial.

SPSS negative binomial estimates the dispersion. Tensr estimates α as well, and prints it with a standard error.
