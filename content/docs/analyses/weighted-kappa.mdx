---
title: Weighted kappa
description: Agreement that treats nearby categories as partial agreement.
category: Categorical
---

## When to use it

Use weighted kappa when two raters use ordered categories and a near miss should count more than a complete miss. Linear weights treat each step the same. Quadratic weights punish larger misses more.

## Assumptions

Both columns are ordered categories. Tensr sorts the level names alphabetically and then treats that order as the scale, so name levels so alphabetical order is the real order (`1`, `2`, `3`, or `low`, `mid`, `high` does not sort as low-mid-high).

## Running it in Tensr

<Steps>
<Step>Analyze → Scale → Weighted Kappa. In chat: “Weighted kappa for rater A and rater B.”</Step>
<Step>Weights start at linear. Quadratic is the other choice.</Step>
</Steps>

## Reading the output

Twelve cases rated 1, 2, or 3. Weights are linear. Levels sort numerically, which is the scale order. Fair agreement uses the same Landis and Koch benchmarks as Cohen’s kappa. Cutoffs: Landis & Koch, 1977.

| Weighted κ | Unweighted κ | SE | z | p |
| ---: | ---: | ---: | ---: | ---: |
| 0.323 | 0.25 | 0.222 | 1.454 | .146 |

The contingency table, with rater A down the rows:

| rater_a | 1 | 2 | 3 |
| --- | ---: | ---: | ---: |
| 1 | 2 | 2 | 0 |
| 2 | 0 | 2 | 2 |
| 3 | 1 | 1 | 2 |

p = .146, so this set does not show weighted agreement beyond chance.

## Reporting (APA 7)

Linear weighted κ was .32, SE = 0.22, z = 1.45, p = .146, indicating fair agreement. N = 12.

## Coming from SPSS

Analyze → Scale → Weighted Kappa. SPSS asks for linear or quadratic weights.
