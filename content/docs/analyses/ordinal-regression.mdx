title: Ordinal regression
description: Predict an ordered category, such as a 1-to-5 rating.

## When to use it

Use ordinal regression when the outcome has ordered categories and the gaps between them are not equal scores. A 1-to-4 rating is the usual case. The model has one slope per predictor and a threshold between each pair of adjacent categories.

## Assumptions

The outcome is ordered. The proportional-odds idea is that one slope works at every threshold. Tensr does not test that assumption.

## Running it in Tensr

<Steps>
<Step>Analyze → Regression → Ordinal. In chat: “Ordinal regression of rating on practice.”</Step>
<Step>Dependent is the ordered outcome. Independents need at least one predictor.</Step>
<Step>Confidence level starts at 0.95. Include constant is on the request. The dispatcher does not pass it through.</Step>
</Steps>

## Reading the output

One hundred and eighty people. `rating` is 1 through 5. `practice` is a noisy predictor, not a clean step up the scale. Counts were 31, 48, 35, 40, and 26.

| Term | Estimate | p-value |
| --- | ---: | ---: |
| practice | 0.228 | .138 |
| 0.0/1.0 | −1.614 | < .001 |
| 1.0/2.0 | 0.291 | .028 |
| 2.0/3.0 | −0.228 | .144 |
| 3.0/4.0 | 0.212 | .153 |

The practice row is the slope. It is not significant here (p = .138). The other rows are thresholds between adjacent rating codes. AIC was 579.306 and the log-likelihood was −284.653.

## Reporting (APA 7)

An ordinal regression did not show that practice predicted rating, B = 0.23, p = .14. N = 180.

## Coming from SPSS

Analyze → Regression → Ordinal.

SPSS PLUM prints thresholds and a slope, with standard errors and Wald tests. Tensr’s table uses Term, Estimate, and p-value.
