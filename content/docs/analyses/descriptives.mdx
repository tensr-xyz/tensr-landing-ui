## When to use it

Use descriptives when you want to see what a variable looks like before you test anything. They answer “what is typical, and how spread out are the scores?” For example: in a class of 24, what is the average exam score, and how many students sat each teaching method?

## Assumptions

Descriptive statistics do not assume a normal distribution or equal groups. Tensr does not run a normality test as part of this procedure.

Each statistic uses the non-missing values in that column. A row can count toward the mean of one column and be skipped for another. The report also states how many rows are complete on every selected column.

## Running it in Tensr

<Steps>
<Step>Analyze → Descriptive Statistics → Descriptives. In chat, ask for descriptives, for example “Summarise score and method.”</Step>
<Step>Put every column you want summarised into the column list. Leave it empty to include every column.</Step>
<Step>Tick the statistics you want. The dialog starts with mean, median, standard deviation, range, minimum, and maximum switched on. Variance, skewness, kurtosis, and the standard error of the mean start off.</Step>
</Steps>

## Reading the output

Tensr opens with a frequency table for each column. Counts are the number of rows with that value. Percent uses every row, including missing rows, as the base. Valid percent uses non-missing rows. Cumulative percent adds the valid percents down the table.

The Statistics block and the Descriptive statistics table are the numeric summary. N Valid is how many values were present. The mean is the arithmetic average. The standard deviation uses the sample formula (divide by N − 1).

Above the tables, the report lists dataset rows, listwise-complete rows (no missing value on any selected column), and the number of columns. There is no p-value. Nothing here is “significant.”

With charts on, the first chart is a histogram titled “Distribution of” plus the column name. Further numeric columns, up to three more, get their own histograms.

## Reporting (APA 7)

Exam scores (N = 24) averaged 73.29 (SD = 5.92). Eight students were assigned to each teaching method (lecture, workshop, and online).

## Coming from SPSS

The path stored for this procedure is Analyze → Descriptive Statistics → Frequencies. Tensr’s own menu label is Descriptives. SPSS Descriptives (the other menu item) does not print a frequency table.
