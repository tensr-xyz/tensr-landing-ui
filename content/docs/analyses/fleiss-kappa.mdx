## When to use it

Use Fleiss’ kappa when three or more raters each code the same cases. Cohen’s kappa is the two-rater version.

## Assumptions

Each column is one rater. Every rater uses the same categories. Tensr needs at least three rater columns.

## Running it in Tensr

<Steps>
<Step>Analyze → Scale → Fleiss Kappa. In chat: “Fleiss’ kappa for these rater columns.”</Step>
<Step>Select at least three columns. Categories are inferred from the values unless you pass a list.</Step>
</Steps>
