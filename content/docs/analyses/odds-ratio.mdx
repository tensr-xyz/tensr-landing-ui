## When to use it

Use an odds ratio when both variables are binary and you want the odds of one level in the first group divided by the odds in the second. Levels are sorted alphabetically. The first outcome level is the event, and the first group level is the group in the numerator.

## Assumptions

Both columns have exactly two levels. This is the same 2×2 table as Fisher’s exact test, with the odds ratio as the headline number.

## Running it in Tensr

<Steps>
<Step>Analyze → Descriptive Statistics → Odds Ratio. In chat: “Odds ratio of group by outcome.”</Step>
<Step>Name the levels so alphabetical order matches the comparison you want.</Step>
</Steps>

## Reading the output

The same weak 2×2. The odds ratio should sit near 1, and the interval should be read before the point estimate.

| exposed | No | Yes |
| --- | ---: | ---: |
| No | 28 | 15 |
| Yes | 23 | 24 |

Odds ratio for `exposed` × `case`, n = 90. The primary result is not significant (p = .140). This is not large enough to treat the comparison this page is about as a reliable association.
