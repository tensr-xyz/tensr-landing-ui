## When to use it

Use the Wilcoxon signed-rank test instead of a [paired t-test](/docs/analyses/ttest-paired) when the differences are skewed or the scores are ordinal. It ranks the size of each person’s change and looks at the direction.

## Assumptions

Each row is one pair. Differences of zero are ties and drop out of the rank sum.

## Running it in Tensr

<Steps>
<Step>Analyze → Nonparametric Tests → 2 Related Samples. In chat: “Wilcoxon signed-rank of before and after.”</Step>
<Step>Before column and after column are the two measurements. The ranked difference is before minus after.</Step>
</Steps>

## Reading the output

Eight pairs. Six scores fell, and two did not change.

| W | Median difference | p | n |
| ---: | ---: | --- | ---: |
| 0 | 1.000 | .031 | 8 |

W = 0 because every non-tied change went the same way, so the smaller rank sum is zero. That is a real statistic, not a missing p-value. The median of the differences is 1. p = .031. The matched-pairs r uses the same labels as Mann–Whitney: |r| below 0.1 is negligible, 0.1 ≤ |r| < 0.3 is small, 0.3 ≤ |r| < 0.5 is medium, and |r| ≥ 0.5 is large. Cutoffs: Cohen, 1988.

## Reporting (APA 7)

Scores were lower after the session than before it, Wilcoxon signed-rank W = 0, p = .031. The median difference (before − after) was 1.

## Coming from SPSS

Analyze → Nonparametric Tests → 2 Related Samples. SPSS may label the statistic T rather than W.
