## When to use it

Use exploratory factor analysis when you do not yet want to fix which items belong to which factor. You ask how many factors the correlations suggest, then read the loadings. If you already have a model, use [confirmatory factor analysis](/docs/analyses/confirmatory-factor-analysis).

## Assumptions

Variables are numeric and are standardized before fitting. Rows with any missing value are dropped. Tensr extracts factors by maximum likelihood. It does not rotate them, and the request has no rotation or extraction menu. There is no KMO or Bartlett test.

## Running it in Tensr

<Steps>
<Step>Analyze → Dimension Reduction → Factor. In chat: “Factor analysis of these items, two factors.”</Step>
<Step>Select at least two columns. Leave the factor count empty, or set it from 1 to 50.</Step>
</Steps>

An empty factor count keeps up to five factors, and never more than the number of variables or one less than the number of complete rows.

## Reporting (APA 7)

EFA on 6 variables, n = 120. Report the estimate in the table. This procedure is not summarised by one p-value.

## Coming from SPSS

Analyze → Dimension Reduction → Factor. SPSS asks for an extraction method and a rotation. Tensr always uses maximum likelihood and does not rotate.
