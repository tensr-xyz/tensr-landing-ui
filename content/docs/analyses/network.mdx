## When to use it

Use this when the rows are relationships, not people-by-variable scores. An edge list has a source column and a target column. An adjacency block is a square set of columns, one per node. The result is who is central, how dense the graph is, and how it splits into communities.

## Assumptions

Give either an edge list or adjacency columns, not a vague mix. Node names are read as text. An optional weight column is numeric. A graph with no nodes is an error. Centrality uses an undirected reading of the links.

## Running it in Tensr

<Steps>
<Step>Analyze → Network → Centrality. In chat: “Centrality for this edge list.”</Step>
<Step>For an edge list, set source and target. Weight is optional.</Step>
<Step>Or set adjacency columns for a square matrix and leave source and target empty.</Step>
</Steps>

## Coming from SPSS

The product menu is Analyze → Network → Centrality. SPSS does not have this dialog. The spring layout is a scatter of nodes, with a fixed seed so the picture does not jump between runs.
