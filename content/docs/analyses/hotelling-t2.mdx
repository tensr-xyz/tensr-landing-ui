## When to use it

Use Hotelling’s T² when you have exactly two groups and several numeric outcomes. It is the multivariate version of the independent-samples t-test. For example: do lecture and workshop students differ on recall and confidence at the same time?

Three or more groups: use [MANOVA](/docs/analyses/manova). One outcome: use the [independent-samples t-test](/docs/analyses/ttest-independent).

## Assumptions

The outcomes are numeric. The two groups are separate. The outcomes should be roughly multivariate normal, with a similar covariance pattern in each group.

Tensr does not test those assumptions. It does compute η² from the T² statistic and prints it when it is available. You cannot turn that off.

## Running it in Tensr

<Steps>
<Step>Analyze → Correlate → Hotelling's T². In chat: “Hotelling’s T-squared of recall and confidence by method.”</Step>
<Step>Group column must contain two groups, or you pass exactly two labels in group values. Dependent columns are the numeric outcomes.</Step>
<Step>There is no post-hoc option and no equal-covariance switch.</Step>
</Steps>

## Reading the output

The same 16 students as the MANOVA example: eight Lecture, eight Workshop, outcomes recall and confidence. Lecture is group 1, so differences are Lecture minus Workshop.

Metrics: T² = 39.2, F = 18.2, p < .001, η² = 0.737.

T² is large when the groups are far apart across the outcomes together. Tensr converts it to an F so you can read a p-value. p < .001 means the two groups differ on the set of outcomes. η² here is T² / (T² + N − 2). 0.737 means a large share of the multivariate variation is between the two teaching methods. In a real class it will be much smaller. The MANOVA on these same rows reported Pillai’s trace of 0.737 and the same F and p. For two groups those tests agree.

Group means:

| Variable | Lecture mean | Workshop mean | Difference |
| --- | ---: | ---: | ---: |
| recall | 6 | 8 | -2 |
| confidence | 3.125 | 5.125 | -2 |

The difference column is not a significance test for that one variable. Both gaps point the same way (workshop higher), which is why the joint test is decisive. The chart is a box plot of recall by method, the first dependent column only.

## Reporting (APA 7)

A Hotelling’s T² test compared lecture and workshop students (n = 8 each) on recall and confidence. The groups differed, T² = 39.20, F(2, 13) = 18.20, p < .001, η² = .74. Workshop means were higher on recall (8.00 versus 6.00) and on confidence (5.13 versus 3.13).

The F degrees of freedom are the ones returned with the result: 2 and 13. The metrics line prints F as 18.2 and does not repeat those df.

## Coming from SPSS

The path stored in Tensr is Analyze → Compare Means → Hotelling. The menu you actually open is Analyze → Correlate → Hotelling's T².

SPSS often reaches this test through Multivariate GLM with two groups. Tensr prints T², the converted F, p, η², and the two group means. It does not print a covariance matrix or a univariate t for each outcome.
