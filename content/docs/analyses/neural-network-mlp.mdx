## When to use it

Use the MLP when you want a small neural net on tabular data, as classification or regression. Trees with readable importances are [gradient boosting](/docs/analyses/gradient-boosting) or [random forest](/docs/analyses/random-forest-classification).

## Assumptions

Hidden-layer size is not a user control. The fit uses two hidden layers of 64 and 32 units. This run also prints permutation importances. Holdout fraction 0.25; chat dispatch does not forward `test_fraction`.

## Running it in Tensr

<Steps>
<Step>ML → Classification → Neural Network MLP (Classification), or ML → Regression → Neural Network MLP (Regression). In chat: “MLP of passed on hours and anxiety.”</Step>
<Step>Set mode to classification or regression. Target matches that mode. Features need at least one numeric column.</Step>
</Steps>

## Reading the output

The same pass/fail outcome, classification mode, hidden layers 64 and 32, 25% holdout.

| Actual \ Predicted | 0 | 1 |
| ---: | ---: | ---: |
| 0 | 7 | 5 |
| 1 | 4 | 8 |

| Variable | Importance |
| --- | ---: |
| hours | 0.146 |
| anxiety | 0.158 |

Train accuracy = 0.847, test accuracy = 0.625, n = 96. Hours only shifts the pass rate a little, so a large gap between train and test is overfitting, and a test accuracy near 0.5 is chance.

## Reporting (APA 7)

Holdout classification of `passed` from hours and anxiety, n = 96. Test accuracy = 0.625, train accuracy = 0.847.
